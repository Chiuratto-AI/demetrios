KNOWN PARSER LIMITATIONS DISCOVERED

Issue: Parser fails when multiple let assignments (with division) precede
a let mut + while loop combination in function parameters.

Example that fails:
  fn sim(dose, vd, cl, t) {
    let k = cl / vd        // OK
    let dt = 0.001         // OK
    let c_init = dose / vd // OK (individually)
    let mut c = c_init     // FAILS when combined with next
    while t < ... { }
  }

Workaround: 
- Use working models already created (darwin_ode_working.d pattern)
- Compute directly in main() instead of functions
- Already applied to all current 14-compartment models

Impact: Medium - doesn't affect existing working models, but limits
modularization of multi-drug validation functions.
