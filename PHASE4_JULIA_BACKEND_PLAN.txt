PHASE 4: JULIA BACKEND CODE GENERATOR
Date: December 8, 2025
Status: DESIGN & IMPLEMENTATION

OBJECTIVE:
Generate Julia code from Demetrios PBPK models to integrate with
DifferentialEquations.jl and Unitful.jl

ARCHITECTURE:

1. Text-Based Code Generator (julia_codegen.rs)
   Input: HLIR (High-Level Intermediate Representation)
   Output: Julia source code (.jl files)
   
2. Type Mapping
   Demetrios → Julia:
   - i32 → Int32
   - i64 → Int64
   - f64 → Float64
   - f64@mg_per_L → Float64 (units as comments)
   - Array[T] → Vector{T} or Array{T}
   
3. Function Generation
   - Generate function signatures
   - Generate ODE function (du/dt format)
   - Generate parameter struct
   - Generate initial conditions

4. DifferentialEquations.jl Integration
   - Generate ODEProblem
   - Generate SciMLProblem interface
   - Generate solve() calls
   - Generate output format

IMPLEMENTATION PLAN:

Step 1: Create julia_codegen.rs module
Step 2: Implement type converter (Demetrios → Julia)
Step 3: Implement function codegen
Step 4: Implement ODE function generation
Step 5: Implement parameter struct generation
Step 6: Test with existing PBPK models
Step 7: Validate output with Julia compiler

DELIVERABLES:

1. julia_codegen.rs (500-1000 lines)
   - Main code generator struct
   - Type conversion functions
   - Code generation methods

2. Generated Julia files:
   - pbpk_model.jl (main model)
   - parameters.jl (drug parameters)
   - run_simulation.jl (driver script)

3. Documentation:
   - Julia backend API
   - Generated code examples
   - Integration guide

VALIDATION:

For each Demetrios PBPK model:
1. Generate Julia code
2. Compile with Julia
3. Run simulation
4. Compare results with Demetrios output
5. Benchmark performance

SUCCESS CRITERIA:
✓ Generate valid Julia code
✓ Code compiles without errors
✓ Simulations produce same results as Demetrios
✓ Performance benchmark vs Demetrios
