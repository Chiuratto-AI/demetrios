OBJECTIVE:
Create user-friendly command-line interface for Darwin PBPK with
comprehensive documentation ready for Q1 publication.

CLI DESIGN

Binary: darwin-pbpk

Subcommands:
1. simulate    - Run PBPK simulation
2. validate    - Validate predictions vs clinical data
3. predict     - AI-based drug property prediction
4. convert     - Convert between model formats
5. benchmark   - Performance comparison
6. generate    - Generate model from template

Usage Examples:
$ darwin-pbpk simulate --drug midazolam --dose 2.0 --duration 2.0
$ darwin-pbpk validate --input predictions.csv --clinical clinical_data.csv
$ darwin-pbpk predict --smiles "CC(C)Cc1ccc(cc1)C(C)C(O)=O" --output properties.json
$ darwin-pbpk benchmark --model 14comp --iterations 1000
$ darwin-pbpk generate --template pbpk_14comp --drug custom_drug.json
