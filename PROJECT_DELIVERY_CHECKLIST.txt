KNOWN LIMITATIONS & WORKAROUNDS
================================================================================

Demetrios Compiler (Not blocking production use):
1. Parser bug with multiple let assignments → Use inline computation
   Status: Documented, workaround applied
   Impact: Affects code modularity, not correctness

2. f64 function return propagation → Use inline computation
   Status: Documented, workaround applied
   Impact: Requires slightly more verbose code

Model Limitations (By design):
1. 1-Compartment: Assumes instant distribution
   → Use 3 or 14-comp for complex PK

2. 3-Compartment: Limited organ specificity
   → Use 14-comp for organ toxicity prediction

3. 14-Compartment: Standard 70kg, no active transport yet
   → Manual scaling for other weights (allometry: CL ∝ weight^0.75)
   → Active transport coming Phase 6B
