BUGS DISCOVERED & DOCUMENTED
================================================================================

BUG #1: f64 Function Return Propagation
- Severity: Medium
- Location: Interpreter
- Issue: c = function_call(c) doesn't update c in while loops
- Impact: Affects modularity, not core functionality
- Workaround: Use inline arithmetic ✓ APPLIED
- Status: DOCUMENTED

BUG #2: Parser Multiple Let Assignment
- Severity: Medium
- Location: Parser
- Issue: Multiple let with division before let mut+while fails
- Example: let k = cl/vd; let dt = 0.001; let c = dose/vd; let mut x = c;
- Impact: Limits function modularity
- Workaround: Compute in main() or inline ✓ APPLIED
- Status: DOCUMENTED

Both bugs have workarounds and don't block functionality.
