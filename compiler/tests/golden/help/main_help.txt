Demetrios Compiler

A biomedical domain language with semantic type checking

USAGE:
    demetrios [OPTIONS] <INPUT>

ARGS:
    <INPUT>    Source file to compile

OPTIONS:
    -o, --output <FILE>           Output file path
        --error-format <FORMAT>   Error output format [human|json] (default: human)
        --semantic-threshold <N>  Default semantic distance threshold (default: 0.3)
        --ontology <PATH>         Additional ontology file to load
        --warn <WARNING>          Enable specific warning
        --allow <WARNING>         Disable specific warning
        --deny <WARNING>          Treat warning as error
    -v, --verbose                 Verbose output
    -q, --quiet                   Suppress non-error output
        --explain <CODE>          Explain an error code
    -h, --help                    Print help information
    -V, --version                 Print version information

EXAMPLES:
    demetrios program.dm -o program
    demetrios --error-format=json src/main.dm
    demetrios --ontology=custom.owl program.dm

For more information, visit https://demetrios-lang.org
