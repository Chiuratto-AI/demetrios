# Release v0.40.0 - AlphaDemetrios: Epistemic MCTS

**Release Date**: December 18, 2025

## Highlights

This release introduces **AlphaDemetrios**, a complete neuro-symbolic MCTS system combining neural network guidance with epistemic uncertainty tracking. This marks a major milestone in Demetrios' machine learning capabilities.

### Core Innovation

> **Epistemic PUCT**: Exploration driven by knowledge gaps, not just visit counts.

The key formula:
```
score = Q + c_puct × U + c_epistemic × √variance
```

Where variance represents epistemic uncertainty (what the agent doesn't know), enabling principled exploration via active inference.

- Beta posterior updates per action

- Generate games via MCTS-guided play
- Extract policy targets from visit counts
- Train on (state, policy, outcome) tuples

#### Provenance Tracking
- Content hashing for model versions
- Loss tracking (before/after updates)
- Confidence scoring based on improvement
- Chain verification for audit trails

## Technical Details

### Beta Distribution Updates

Instead of simple averaging, AlphaDemetrios uses Beta posteriors:

```demetrios
// Update Beta parameters with outcome
child_alpha = child_alpha + outcome      // wins
child_beta = child_beta + (1 - outcome)  // losses

// Compute mean and variance
mean = alpha / (alpha + beta)
variance = alpha * beta / ((alpha + beta)² × (alpha + beta + 1))
```

### Provenance Structure

```demetrios
struct ProvenanceEntry {
    content_hash: f64,    // Model version identifier
    iteration: f64,       // Training step number
    loss_before: f64,     // Loss before update
    loss_after: f64,      // Loss after update
    confidence: f64       // Update quality score
}
```
